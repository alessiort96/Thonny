# Thonny

Este repositorio es un punto de partida mínimo para comenzar a programar con Python.

## ¿Dónde programo?

1. Abre el proyecto en tu editor o IDE favorito (por ejemplo, [Thonny](https://thonny.org/)).
2. Edita el archivo `src/main.py`, que contiene un espacio con líneas numeradas listo para que escribas tu código.
3. Crea módulos adicionales dentro de la carpeta `src/` si necesitas organizar mejor tu proyecto.
4. Ejecuta tus scripts con `python nombre_del_archivo.py` desde la terminal.
5. Añade pruebas o ejemplos dentro de `tests/` para comprobar el funcionamiento de tu código.

## Estructura sugerida

```
Thonny/
├─ src/
│  └─ main.py
└─ tests/
   └─ test_main.py
```

## Requisitos

- Python 3.10 o superior

## Cómo ejecutar

```bash
python src/main.py
```

En `src/main.py` encontrarás un bloque de líneas numeradas donde puedes comenzar a escribir tu lógica.
